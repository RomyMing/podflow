# Design System Theme

> **Design history:** this file records an early visual-system draft. The current UI implementation and screenshots are authoritative.
 
## Colors
 
*   **Color Mode**: Light
*   **Primary Color**: `#2563EB` (A vibrant blue, ideal for primary actions and key interactive elements.)
*   **Neutral Color**: `#111827` (A dark, almost black neutral, providing a strong contrast and base for backgrounds.)
 
## Typography
 
*   **Headline Font**: Inter (Modern, sans-serif, offering excellent readability for titles.)
*   **Body Font**: Inter (Consistent with headlines for a cohesive textual experience.)
*   **Label Font**: Inter (Ensuring clear and legible labels across the UI.)
 
## Shape and Spacing
 
*   **Roundedness**: Moderate (Default rounded corners for a balanced and friendly aesthetic.)
*   **Spacing**: Normal (A comfortable and standard amount of whitespace, promoting good readability and visual organization.)
