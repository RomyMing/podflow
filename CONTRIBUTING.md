# Contributing to PodFlow

PodFlow is currently maintained as a personal portfolio project.

## Issues and feedback

Bug reports, reproducible problems, documentation corrections, and focused product feedback are welcome through GitHub Issues. Before opening an Issue:

1. Search existing Issues for the same problem.
2. Remove API keys, tokens, personal audio, phone numbers, and other sensitive data.
3. Include the PodFlow version, operating system, run mode, expected behavior, actual behavior, and minimal reproduction steps.

Questions about vulnerabilities or exposed credentials must follow [SECURITY.md](SECURITY.md) and must not be posted publicly.

## Pull requests

External code pull requests are not currently accepted. Please open an Issue first if you want to propose a change. The maintainer may implement accepted ideas in the private development repository and publish them in a later reviewed snapshot.

Opening an Issue or sharing an idea does not change the repository's copyright status and does not grant a license to the source code. See [LICENSE](LICENSE).
